# 算法工程师学习档案

> 目标：在保持现有工作的前提下，用约 12 个月建立可转行的算法工程能力。第一年目标为具备投递 AI 应用工程师、初中级算法工程师及相邻工程岗位的作品与基础。

## 使用方式

- 每次学习后更新“学习日志”；不追求写得长，只记录实际完成、错误与下次动作。
- 数学采用“概念—手算/推导—模型场景—间隔复习”循环，而非一次性学完。
- 学习目标是理解并应用，不以大学数学课的完整证明体系为目标。
- 英语与技术同步：每节课保留 3–5 个核心英文术语与一个简短技术表达；项目 README 先写中文，再逐步补充英文版。重点是读懂文档、代码与岗位描述，不额外增加独立背诵负担。

### 单节课结构与推导深度

> 课程由“转向算法工程师”的目标决定推导深度，而不是机械要求所有公式都手推。每个新模型或新算法按以下顺序讲授，不能因 Notebook 已准备好而跳步：
>
> 1. **问题与直觉**：它要解决什么问题，为什么需要它。
> 2. **最小数学推导**：先定义符号，手算一个最小例子，写出核心公式与每一项含义。
> 3. **算法流程**：把推导连接到训练或预测的步骤。
> 4. **从零/最小代码**：逐行对应公式；先解释，再由学习者编写或运行。
> 5. **实验与评估**：观察训练/验证结果，解释现象与局限。
> 6. **检查与归档**：用 2–3 个问题检验理解，记录易错点、下次动作和英语词汇。
>
> 对每个概念，先明确其学习层级：
>
> - **必须手算/推导**：直接决定模型训练、损失、梯度、切分或概率含义，且会影响实现、调参和面试表达。例如线性回归梯度、BCE、Softmax、决策树的一次 Gini/信息增益切分。
> - **必须理解，不要求完整推导**：理解输入输出、核心假设、关键超参数与失效方式即可。例如 Adam 的完整偏差修正、随机森林的随机采样证明、Transformer 的全部工程细节。
> - **必须会用并能解释结果**：工程工具与 API，重点是正确流程、数据边界、评估和复现。例如 Pipeline、交叉验证、网格搜索、模型保存。
>
> “达到要求”指能完成与该概念对应层级的能力，而不是只会调用库，也不是为了推导而推导。

### 需要巩固

- 矩阵乘列向量的输出仍需注意是向量，不是单个标量。
- 链式法则计算时容易漏掉外层平方产生的系数 `2`。

- 已理解协方差：同涨同跌通常为正协方差，反向变化通常为负协方差。
- 已理解协方差矩阵：有 `d` 个特征时为 `d×d`；对角线为方差，非对角线为两特征协方差，矩阵对称。
- 已理解 PCA 的完整主流程：中心化 → 协方差矩阵 → 特征值/特征向量 → 按特征值选择主成分 → 投影降维。
