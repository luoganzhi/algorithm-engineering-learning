### 2. 数学与优化

**问：为什么线性回归解析解中需要 $X^T$？**

答：数据矩阵 $X$ 通常是 $n \times d$，预测为 $Xw$。最小二乘的一阶条件为 $X^T(Xw-y)=0$；左乘 $X^T$ 后得到 $X^TXw=X^Ty$，从而在可逆时得到 $w=(X^TX)^{-1}X^Ty$。

**问：为什么 $X^TX$ 需要可逆？**

答：只有可逆时才能写出唯一的普通逆矩阵解。不可逆往往意味着特征线性相关或样本不足；实践中可用伪逆或加 L2 正则化。

**问：协方差如果有三个特征怎么计算？**

答：三个特征就构成 $3 \times 3$ 协方差矩阵。对角线是每个特征的方差，非对角线是任意两个特征的协方差，矩阵关于对角线对称。

**问：PCA 是什么？**

答：PCA（Principal Component Analysis，主成分分析）通过中心化、计算协方差矩阵、求特征值/特征向量、选择最大特征值对应方向，再将数据投影到这些方向，实现保留主要变化的降维。

### 3. 分类、损失与评估

**问：为什么二分类使用二元交叉熵？**

答：二分类标签可看作伯努利分布。二元交叉熵正是伯努利模型的负对数似然；它与 sigmoid 配合时，对 logit 的梯度简化为 $p-y$，训练稳定且含义清楚。

**问：`predict` 与 `predict_proba` 有何不同？**

答：`predict_proba` 输出每类概率；`predict` 根据当前阈值或最大概率给出最终类别。阈值调整应基于概率，而不是只看类别输出。

**问：FPR 是否为 $FP/(FP+TP)$？**

答：不是。$FP/(FP+TP)$ 是 $1-\text{Precision}$；误报率 $\text{FPR}=FP/(FP+TN)$，分母是所有真实负类。

**问：AUC 与固定阈值下的 Accuracy 有何不同？**

答：AUC 衡量模型跨全部阈值的排序能力；Accuracy 衡量某个固定阈值下的分类正确比例。即使 AUC 高，仍要按漏报与误报成本选择业务阈值。

### 4. 数据处理与防泄漏

**问：为什么标准化只在训练集 `fit`？**

答：均值、标准差、中位数、类别词表等都是从数据中“学到的统计量”。如果让验证集或测试集参与 `fit`，等于训练时提前看到了未来数据，形成 data leakage（数据泄露）。

**问：`df = dataset.frame.copy()` 是什么？**

答：`dataset.frame` 是 sklearn 数据集提供的 DataFrame；`.copy()` 创建一份独立副本，之后修改 `df` 不会意外改动原对象。

**关键提问：决策树只有 Gini 吗，熵不是也能衡量纯度吗？**

答：两者都可用。Gini impurity 与 entropy 都是节点混乱度；节点越纯，值越小。sklearn 的 `DecisionTreeClassifier` 默认 `criterion="gini"`，也可设为 `criterion="entropy"`。两者实践效果通常接近。

**检查点回答：**

1. 不限制深度的树会持续按训练样本切分，直到记住偶然细节，因此常出现过拟合。
2. 训练准确率提高、验证准确率下降，是过拟合的信号。
3. 用验证集选择 `max_depth`，因为模型未定型前不能根据测试集反复做选择；测试集只用于最终、一次性的泛化评估。

**新增 Notebook 内容：**

已加入 `plot_tree` 可视化单元，训练并绘制 `max_depth=3` 的决策树。阅读图时，依次看切分规则、Gini、不纯度、样本数 `samples` 和类别计数 `value`。

**读图易错点：**

树图中相邻的数字含义不同，必须分开读。当前树的左孩子节点为：`worst concave points <= 0.136`、`gini = 0.161`、`samples = 284`。其中 `0.136` 是阈值，`0.161` 是切分前的节点混乱度，`284` 是进入该节点的训练样本数。

**检查点：PCA 为什么先标准化：**

回答正确：若不标准化，各特征原本的量纲和数值刻度不同，方差就无法直接比较；数值范围大的特征会人为主导 PCA 的方差方向。标准化后，各特征在相近尺度上参与比较，主成分更能反映数据结构而不只是单位大小。

**追问：PCA 为什么使用方差：**

方差衡量样本沿某个方向的分散程度。投影后方差很小的方向会让样本挤在一起，几乎不保留区分信息；方差大的方向保留更多样本差异。PCA 选择最大方差方向，也等价于最小化降维后还原数据的平方误差。注意 PCA 不使用标签，高方差方向未必一定最利于分类，是否使用仍需验证。

**PCA 接入分类 Pipeline：**

新增 `notebooks/w8_PCA接入分类Pipeline.ipynb`。使用 Pipeline 保证每一折交叉验证都按“仅用该折训练数据标准化 → PCA 学习主方向 → 逻辑回归训练”的顺序执行。对比结果：标准化逻辑回归验证均值为 0.978、标准差为 0.010；加入保留 95% 方差的 PCA 后，验证均值为 0.982、标准差为 0.005。完整开发集上 PCA 将 30 个特征压缩为 10 个主成分，累计解释方差约为 95.3%。结论：在本数据上 PCA 既降维，也使验证结果略有改善；但主成分可解释性低于原始特征，因此应按任务目标选择。

**检查点：Pipeline 中标准化与 PCA 的顺序：**

回答正确：PCA 依靠方差决定主方向，必须先标准化以避免原始特征刻度不同影响方差。补充：若先 PCA，主方向已经根据失真的方差确定；之后再标准化无法重新修正已选的主方向。因此顺序必须是 StandardScaler → PCA → 分类器。

**K-Means 聚类与 K 值选择：**

新增 `notebooks/w8_KMeans聚类与K值选择.ipynb`。已学习 K-Means 的“分配到最近中心 → 用簇内均值更新中心”迭代；理解 inertia 是簇内平方距离和，silhouette 衡量簇内紧密与簇间分离。鸢尾花标准化数据上，K 从 2 到 8 的 silhouette 在 K=2 时最高（约 0.582），K=3 时约为 0.460；为对照三个已知物种，额外查看 K=3 的簇组成。结果显示 setosa 被独立聚出，但 versicolor 与 virginica 存在混合。结论：聚类编号不是类别名称，K-Means 只按几何距离分组；选择 K 要结合指标与业务/领域解释，而不能只机械取某个最高分。

**英语词汇：**

- clustering：聚类
- centroid：中心点
- inertia：簇内平方距离和
- silhouette score：轮廓系数

**检查点：cluster id 与真实类别：**

回答正确：K-Means 只依据特征距离计算簇，不读取真实标签；cluster id 是算法内部编号，没有真实类别名称含义。即使簇数量与真实类别数量相同，也不能默认一一对应，必须在训练后借助领域知识或标签进行解释。

**检查点：异常值为什么影响 K-Means：**

回答正确：异常值会显著影响簇内均值，因此拉偏聚类中心。补充：K-Means 最小化平方距离，异常值的远距离会被平方进一步放大；被拉偏的中心还会改变周围正常样本的簇分配。
